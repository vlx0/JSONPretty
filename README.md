# JSONPretty

**Каша ↔ читаемый JSON.**

Автор: **darkshade** ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 6 — «Текст»** · **день 40**.

## Что умеет

- **Красиво** — отступы и переносы  
- **Сжать** — одна строка  
- если JSON битый — покажет строку и колонку ошибки  
- кириллица без `\uXXXX`  
- из буфера / в буфер  

**Ctrl+Enter** — красиво.

## Запуск

`start.bat` · `python -m jsonpretty` · `run_jsonpretty.pyw`
