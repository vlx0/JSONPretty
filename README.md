# JSONPretty

**JSON одной простынёй — читать невозможно.** Вставил → «Красиво» или «Сжать».

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 6 — «Текст»** · **день 40**.

---

## Что умеет

- делает читаемый JSON с отступами
- сжимает обратно в одну строку
- если JSON битый — пишет строку и колонку ошибки
- кириллица без `\uXXXX`
- из буфера / в буфер

**Ctrl+Enter** — красиво.

## Запуск

```bat
start.bat
```

или `python -m jsonpretty` / `run_jsonpretty.pyw`.

Нужен Python 3.10+ с tkinter.
